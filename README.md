# hook-generateur - Rocco / Victoryan
Bonjour, voici l'outil gratuit de la semaine. Cet outil est, comme dit, un générateur de hooks, il va donc t'aider à  améliorer tes hooks afin de capter l'attention de ton spectateur/ client. Il est très simple d'utilisation, il suffit de mettre le thème de ta vidéo et ton avatar client cible.
